# Ember Roast Coffee

## Project Descriptions

Ember Roast Coffee is an e-commerce website created for the **Selling Out!** final project. It represent coffee company selling three products:

- Dark Ember Espresso
- Mountain Blend
- Velvet Mocha Roast

## Technologies Used

- HTML5
- CSS3
- Git and GitHub

## Pages Included

- `index.html` — Homepage
- `about.html` — About page
- `shop.html` — Shop page
- `contact.html` — Contact page

## Design Choices

The site uses an **analogous warm color scheme** inspired by roasted coffee:

- Dark Brown: `#3B1F0B`
- Coffee Brown: `#6F4E37`
- Gold: `#C89B3C`
- Cream: `#FFF3E0`

Fonts:

- **Playfair Display** for headings
- **Lato** for body text
